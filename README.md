# A Living Notebook of the Universe
An evolving archive of physics derivations, C++ simulations, and conceptual bridges between matter, energy, and complexity.

This repository is a long-term intellectual project to reconstruct and explore the laws of the universe through structured derivations and computational simulations in C++.
It includes:
1. Physics derivations
2. C++ simulations
3. Conceptual bridges between physics, chemistry, and complex systems
4. Reflections on entropy, stability, and structure

This is a living system. It will evolve over time.
